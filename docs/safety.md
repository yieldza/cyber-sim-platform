# Safety Model

CSP is a **defensive** detection-testing platform. The threat model assumes a
blue team that needs to validate whether their EDR/XDR/SASE/email-gateway
stack actually catches the categories of artifacts they are buying detection
for.

## Payload policy

| Allowed                                                     | Not allowed                                |
|-------------------------------------------------------------|--------------------------------------------|
| EICAR test signature in any container                       | Real malware samples                       |
| Hash mutations (random append, padding, prefix-search)      | Working shellcode / loaders                |
| Format / extension polyglots over EICAR                     | Credential theft modules                   |
| Benign MITRE ATT&CK simulation (planned milestone B)        | Live exploit code or 0-days                |
| Caldera-style benign agent telemetry (planned milestone C)  | Persistent C2 against unauthorized targets |

The boundary is intentionally conservative: every artifact generated by
this platform is detectable by any AV that understands EICAR, which
includes essentially all modern endpoint security products.

## Auth & audit

- Bcrypt + JWT login; admin bootstrapped from env on first start.
- Every generate / mutate / convert / download is logged with user, IP,
  artifact id, and SHA-256 in the `audit_log` table.
- Rate limit: 240 requests / minute / IP at the API gateway.
- The internal Python worker is gated by a static `WORKER_API_KEY` and is
  not exposed outside the docker network.

## Deployment recommendations

- Run on an isolated lab subnet that you own.
- Do **not** expose the API/web ports to the public internet. Put the UI
  behind a VPN or SSO reverse proxy if multiple analysts need access.
- Allow-list outbound EDR telemetry from the test endpoints so that
  detections still reach your SIEM during validation.
- Treat the artifact store (`data/artifacts/`) as quarantine — many
  on-host AVs will scan and quarantine it; that is fine.
