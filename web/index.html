    After download:
    
          • Windows (recommended) — download both csp-agent.cmd and csp-agent.ps1 into the same folder, then run csp-agent.cmd -C2 … -EnrollToken …. The launcher auto-bypasses ExecutionPolicy so you never see the "running scripts is disabled" prompt.
    
          • Windows (manual) — powershell -ExecutionPolicy Bypass -File .\csp-agent.ps1 -C2 … -EnrollToken …
    
          • Linux / macOS — chmod +x csp_agent.py (or run via python3 csp_agent.py …)
    
          • C# — see header comments in the .cs file for dotnet publish build steps.
